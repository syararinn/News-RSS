# 対象ユーザーと利用シーン

## 想定ユーザー

- **開発者自身（個人利用）**：もともとは自分専用のニュースチェックツールとして
  開発されたもので、業務としての外部提供や社外ユーザーを前提としていない。
- 特定のテーマ（政治・経済・スポーツ・地域の話題・業界動向など）を
  **継続的にウォッチしたい人**。
- 複数のニュースサイトを毎回チェックするのが面倒で、**情報収集を自動化したい人**。
- 通勤・通学などのすき間時間に、**スマートフォンでサクッと情報収集したい人**。
- 話題になっているニュースを**効率よく把握したい人**（関連記事のまとめ表示が有効）。

## 典型的な利用シーンの流れ

1. **初期設定**：追いたいテーマのキーワードを登録する
   （例：関心のある分野名や地域名など、自由に設定可能）。
   見たくない情報源やジャンルがあれば、NGワードとしてあわせて登録する。
2. **取得**：画面下部の「取得」ボタンを押す、または自動更新に任せておく。
3. **閲覧**：新しい順・話題順・キーワード順で並び替えながら記事一覧をチェックする。
   気になる記事はタップしてそのまま元サイトを閲覧する。
4. **保存**：あとで読み返したい記事は☆でお気に入りに追加しておく。
5. **通知**：特に見逃したくないキーワードには🔔で通知をONにしておき、
   新着があれば都度アプリを開かなくても気づける状態にする。
6. **切り替え**：関心テーマが複数ある場合は、あらかじめ「キーワードグループ」として
   保存しておき、状況に応じてワンタップで表示を切り替える
   （例：仕事関連のテーマと、プライベートな関心テーマを使い分けるなど）。

## 利用シーンのイメージ

- 朝の身支度・通勤中に、スマートフォンでホーム画面から起動し、
  昨晩からの新着ニュースをまとめてチェックする。
- 特定のイベントや動向が気になる期間だけ、一時的にキーワードを追加し、
  落ち着いたら削除する、といった柔軟な使い方をする。
- 複数の関心分野を横断的に見たいときは「主要」タブで自動仕分けされたニュースを一覧し、
  深掘りしたいテーマがあれば「ニュース」タブでキーワード検索を行う。
