# 差別化ポイントと数字

セールスポイントを、可能な限り数字つきで整理する。
（数値はいずれもリポジトリの実装内容・開発履歴から確認できる事実ベース。）

## 情報収集の自動化・網羅性

- 主要ニュースタブだけで、**9本のRSSフィード**（Yahoo!・Google・NHK・読売など複数媒体・
  複数カテゴリ）を**自動的に横断集約**し、1画面にまとめて表示する。
- ニュースタブでは、登録したキーワードの数だけ自動で順番に検索を行い、
  **キーワード1件につき最大30件・全体で最大100件**まで記事を取得できる。
- 記事タイトルの内容から**7カテゴリ**（政治・経済・国際・スポーツ・芸能・社会・天気）へ
  **自動仕分け**するため、人手でのタグ付け作業が不要。
- タイトルの類似度が一定基準（内部的には約35%以上の一致度）を超える記事は
  自動的に**同一トピックとしてグルーピング**され、「関連◯件」として話題性を可視化する。

## 手間の削減・自動化の範囲

- キーワード登録は**入力して「追加」ボタンを押すだけ**（設定完了まで数秒）。
  複数サイトを手動で巡回する作業がまるごと不要になる。
- キーワードの組み合わせを「グループ」として保存すれば、以降は**ワンタップで
  テーマの切り替え**が可能（キーワードを都度入力し直す必要がない）。
- 自動更新は**1分・3分・5分・10分・15分・30分**の6段階から選べ、
  画面を開いたまま**放置するだけで最新情報が自動反映**される。
- 気になるキーワードは🔔一つで**新着のブラウザ通知**を受け取れるため、
  能動的にチェックしに行く手間そのものを削減できる。

## お気に入り・履歴管理のスケール

- お気に入りは**最大300件**まで保存可能。
- 既読（訪問済み）リンクの履歴は**最大500件**まで自動保持され、
  読んだ記事・未読の記事がひと目でわかる。

## 開発の身軽さ（技術的な特徴）

- フロントエンドは**1ファイル（約1,700行のHTML）**、バックエンドAPIも
  **1ファイル（約160行）**という非常にシンプルな構成でありながら、
  4タブ・通知・自動更新・グループ管理まで一通りの機能を実現している。
- 特別な開発環境がなくても、**サーバーレス関数1本**で外部ニュースサイトのRSS取得・
  文字コード変換・重複除去・除外ワード処理までを完結させている。

## 開発プロセスそのものの特徴（AI活用の裏付け）

  機能追加**であり、プルリクエストとしてレビュー・マージされている
  （キーワードグループ機能、通知機能、絞り込みUIの整理など、複数の機能追加が該当）。
