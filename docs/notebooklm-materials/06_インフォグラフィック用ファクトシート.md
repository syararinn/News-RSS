# インフォグラフィック用ファクトシート

1枚もの資料（インフォグラフィック）向けに、数字とキーワードだけを抜き出した素材集。
NotebookLMの生成結果に反映されなかった場合の手動調整や、
資料作成時の参照用としても使える。

## Before / After 表

| | Before（従来） | After（本ソフト導入後） |
| --- | --- | --- |
| 情報源の確認方法 | 複数サイトを個別に手動巡回 | キーワード登録だけで**9本のRSS**を自動横断集約 |
| 興味テーマの管理 | 都度検索、条件を覚えておく必要あり | 「キーワードグループ」に保存し**ワンタップで切替** |
| 新着の把握 | 自分から見に行かないと気づけない | キーワード単位で**ブラウザ通知**が届く |
| 似た記事の乱立 | 重複・類似記事が並び読みにくい | 類似記事を自動グルーピングし「話題順」で整理 |
| ジャンル分け | 手作業でジャンルを判断 | タイトルから**7カテゴリへ自動分類** |
| 更新の手間 | 手動でリロードして確認 | **1分〜30分**の自動更新に対応 |

## 数字で見る特徴

- **9本**：主要ニュースタブが自動集約するRSSフィード数
- **7カテゴリ**：自動仕分けされるニュースジャンル（政治／経済／国際／スポーツ／芸能／社会／天気）
- **最大100件**：1回の取得で表示できる記事の上限件数
- **最大300件**：お気に入りとして保存できる記事数の上限
- **最大500件**：既読リンクとして自動保持される履歴の上限
- **6段階**：自動更新の間隔（1分／3分／5分／10分／15分／30分）
- **約35%以上の類似度**：関連ニュースとして自動グルーピングする際の内部的な目安
- **v8.9**：継続的な改善を重ねてきたバージョン到達点
- **98件のコミット／6件の機能追加PR**：開発の積み重ねを示す履歴
- **約1,860行**：フロントエンド・バックエンド合計のソースコード規模（シンプルな構成）

## 開発プロセスを表す数字（AI活用の裏付け）

- 開発は**生成AI（AIコーディングエージェント）に要件を伝える**形で進められた。
- 複数の機能追加（キーワードグループ機能、新着通知機能、絞り込みUIの整理など）が、
  AIコーディングエージェントとのやり取りを経てプルリクエストとして作成・レビュー・マージされている。
- 実装の細部（コーディング）はAIエージェントに任せ、人（担当者）は
  **「何を作りたいか」を伝える・確認する役割**に集中する形で開発が進んだ。
