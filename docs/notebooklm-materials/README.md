# NotebookLM 資料フォルダ 利用ガイド

このフォルダは、本リポジトリのソフトウェア（個人向けニュース収集ダッシュボード）を題材にした
**社内向け「AI活用事例」報告**を、Google の NotebookLM（スライド／1枚インフォグラフィック生成機能）で
作成するための「プレゼン専用ソース資料」一式です。

## 1. なぜ設計書・README をそのまま NotebookLM に入れないのか

このリポジトリには `README.md` や実装コード（`index.html` / `api/rss.js`）がありますが、
これらを直接 NotebookLM に読み込ませることは **推奨しません**。理由は次のとおりです。

1. **技術詳細が多すぎる**
   実装コードには HTML/CSS/JavaScript の記述、DOM操作、正規表現によるRSS解析、
   類似度計算アルゴリズムなど、実装上の技術的な詳細が大量に含まれています。
   NotebookLM はソースの内容をほぼそのまま要約する性質があるため、
   これらを読み込ませるとスライドが「コードの説明」になってしまい、
   非エンジニアの上司には伝わりにくい資料になります。

2. **対象読者・伝えたいメッセージが書かれていない**
   コードやREADMEには「誰に」「何を」伝えたいかという情報がありません。
   今回の目的は機能の売り込みではなく、
   **「生成AI（AIコーディングエージェント）を使ってソフトを開発した」という取り組み自体を
   軽く共有すること**です。この目的意識がソースに書かれていないと、
   生成される資料の切り口がぶれてしまいます。

3. **散漫になりやすい**
   READMEやコードコメントは開発者向けの断片的な情報の集まりであり、
   ストーリー（背景→取り組み→成果→展望）としてまとまっていません。

そこで、あらかじめ **人間向けに要約・翻訳し直した資料**（このフォルダの各ファイル）を用意し、
それだけを NotebookLM に読み込ませる方式を取ります。ソース自体に
「伝えたいメッセージ」と「構造（見出し）」を持たせておくことで、
NotebookLM が生成するスライド／インフォグラフィックの精度と一貫性が上がります。

## 2. NotebookLM への投入手順

1. NotebookLM で新しいノートブックを作成する。
2. 「ソースを追加」から、このフォルダ内の Markdown ファイルを **すべて** アップロードする
   （`README.md` 含め、または `README.md` を除いた `01`〜`07` のみでも可）。
   - ファイル数が多いテーマ別分割になっているため、精度よく扱われます。
3. ソースの取り込みが完了したら、右側（または下部）の **「Studio」パネル** を開く。
4. 「スライド」または「インフォグラフィック（1枚の資料）」など生成したい形式を選ぶ。
   - 生成メニューの名称や配置は NotebookLM のバージョンにより変わることがあります。
     「スライド生成」「インフォグラフィック生成」に類する項目を探してください。
5. カスタマイズ欄（プロンプト入力欄）に、`05_NotebookLM生成プロンプト集.md` に用意した
   プロンプト文例をそのまま貼り付ける。
6. まずは **構成案（アウトライン）だけを生成・確認** する（プロンプト集の手順どおり）。
   - アウトラインを見て、内容の過不足・トーンを確認してから本生成に進むこと。
7. 問題なければ本生成を実行し、出力されたスライド／インフォグラフィックを確認・微調整する。

## 3. このフォルダのファイル一覧と役割

| ファイル | 役割 |
| --- | --- |
| `README.md` | 本ファイル。使い方ガイド。 |
| `01_サービス概要.md` | 一言コンセプト、解決したい課題（Before）→提供する解決策（After）、キャッチコピー案。 |
| `02_主な機能.md` | 画面・機能ごとの説明（実装の技術詳細を含まない機能紹介）。 |
| `03_差別化ポイントと数字.md` | セールスポイントを数字つきで整理した一覧。 |
| `04_対象ユーザーと利用シーン.md` | 想定ユーザー像と典型的な利用の流れ。 |
| `05_NotebookLM生成プロンプト集.md` | スライド／インフォグラフィック生成用のプロンプト文例集。 |
| `06_インフォグラフィック用ファクトシート.md` | 1枚もの向けの数字・キーワード素材集（Before/After表など）。 |
| `07_AI活用事例レポート用サマリー.md` | 上司への軽い報告を主眼とした要約。今回のスライド生成の「核」となる文章。 |

## 4. 注意事項

- 本フォルダの資料は、あくまで社内共有・報告用に要約・一般化したものです。
  実在の担当者名や、特定を招きうる個人的な情報（居住エリアや政治的な関心事など）は
  匿名化・一般化して記載しています。
- 本フォルダの作成にあたり、リポジトリ内の設計書やコードそのものは変更していません。
  ドキュメントの追加のみです。
